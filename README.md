# NewsLens

Understand the news, not just the headlines.

NewsLens is an evidence-first news intelligence application that combines reporting from multiple sources into understandable stories.

## Current status

Early development.

## Tech stack

- Python
- Gradio
- Hugging Face
- PostgreSQL
- Open-source NLP models

## Running locally

Create a virtual environment:

```bash
python -m venv .venv
```

Activate it on Windows:

```bash
.venv\Scripts\Activate.ps1
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run:

```bash
python run.py
```


This will evolve substantially as we build.
